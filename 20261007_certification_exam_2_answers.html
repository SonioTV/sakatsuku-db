第2回サカつく検定 1日目の答え【10月7日】

1日目・第1問公式正解確認済み
期限付き移籍は1選手につき何回まで行えるでしょうか？
  1. 制限はない
  2. 5回
  3. 3回
  4. 1回
答え1回

解説：期限付き移籍は同じ選手を何度も繰り返し利用できる育成方法ではありません。監督ノートでは、期限付き移籍は1選手につき1回までと明記されています。

1日目・第2問公式正解確認済み
より高いレベルのリーグに所属する他クラブの選手へ直接オファーを出すためには、何を向上させる必要があるでしょうか？
  1. 監督レベル
  2. クラブレベル
  3. キャンプ地レベル
  4. サポーター数
答え監督レベル

解説：監督Lvを上げることで人事関連の機能が解放・強化され、直接オファーできる対象も拡大していきます。より高いレベルのリーグに所属する選手へ直接オファーを出すために必要なのは監督レベルの向上です。

1日目・第3問公式正解確認済み
「スカウトパワー」は、何をアップさせることで増加するでしょうか？
  1. 資金
  2. スタメン総合力
  3. サポーター数
  4. クラブレベル
答えクラブレベル

解説：スカウトパワーはクラブレベルに応じて増加します。直接オファーの成功にも関係するため、クラブLvを上げることは選手獲得能力の強化にもつながります。

第2回サカつく検定 2日目の答え【10月8日】

2日目・第1問公式正解確認済み
選手総合力「PAS」に【含まれない】能力はどれでしょうか？
  1. キープ力
  2. ロングパス
  3. ショートパス
  4. キック精度
答えキープ力

解説：サカつく2026の選手ステータス定義では、PASは「ショートパス・ロングパス・キック精度」の3項目で構成しています。キープ力はDRBを構成するパラメータなので、PASには含まれません。

2日目・第2問公式正解確認済み
「期限付き移籍」を行うことで上昇するのは、次のうちどれでしょうか？
  1. 限界突破
  2. 覚醒Pt
  3. 疲労
  4. 年俸
答え覚醒Pt

解説：期限付き移籍は選手を他クラブへ送り出して育成するシステムで、複数の移籍先で成長項目として「覚醒Pt」が上昇します。限界値が上昇する移籍先もありますが「限界突破が上昇する」とは表現しない為「覚醒pt」が正解です。

2日目・第3問公式正解確認済み
サカつくモードで選手を「ドリブル覚醒」させた際、次の中で大幅には【増加しない】パラメータはどれでしょうか？
  1. 敏捷性
  2. キープ力
  3. ボールタッチ
  4. 突破力
答え敏捷性

解説：監督ノートでは、ドリブル覚醒で大幅に上昇するパラメータは「突破力・キープ力・ボールタッチ」とされています。敏捷性はこの3項目には含まれません。敏捷性はショートパス覚醒や走力覚醒では大幅上昇の対象になります。

第2回サカつく検定 3日目の答え【10月9日】

3日目・第1問公式正解確認済み
コンディションの増減を2倍にする「欲求」に関して、【該当しない】ものはどれでしょうか？
  1. チームの成績
  2. 疲労度
  3. スキル継承
  4. 試合の出場機会
答えスキル継承

解説：監督ノートでは、欲求として「チーム状態」はチームの成績、「体調」は疲労度、「キャリア」は試合の出場機会を重視し、重視していることに関するコンディションの増減が2倍になると説明されています。「スキル継承」は欲求の対象として挙げられていないため、該当しません。

3日目・第2問公式正解確認済み
コンディションが「天狗」の時の効果はどれでしょうか？
  1. 特別練習が行えない
  2. 絶不調になる
  3. 怪我しやすくなる
  4. 全体練習が行えない
答え特別練習が行えない

解説：監督ノートでは、「天狗」になるとコンディションは絶好調で固定される一方、特別練習や選手継承ができなくなると説明されています。選択肢の中では「特別練習が行えない」が該当します。

3日目・第3問公式正解確認済み
フォーメーション上のポジションで適性が無色の選手の能力は何%に下がるでしょうか？
  1. 30%
  2. 70%
  3. 55%
  4. 85%
答え55%

解説：監督ノートのポジション適正では、能力補正は赤100%・オレンジ85%・黄色70%・無色55%です。そのため、適性が無色のポジションで起用した場合は55%まで低下します。

4日目・第1問公式正解確認済み
サカつくモードの特別練習は何か月ごとに行えるでしょうか？
  1. 6か月後
  2. 1か月後
  3. 翌シーズン
  4. 3か月後
答え3か月後

解説：監督ノートでは、特別練習は実施してから3か月後に再度実施できると説明されています。そのため正解は「3か月後」です。

4日目・第2問公式正解確認済み
「特別練習」を行いたい選手がどのような状態のとき、特別練習を【実行できなくなってしまう】でしょうか？
  1. 不調
  2. スランプ
  3. 絶不調
  4. 怪我や天狗
答え怪我や天狗

解説：監督ノートでは、怪我中の選手は特別練習を行えず、天狗状態の選手も特別練習や選手継承ができなくなると説明されています。不調・絶不調では特別練習の効果量は下がりますが、実行自体は可能です。

4日目・第3問公式正解確認済み
全体練習が強化され、練習効果が向上する「キャンプ」は、1シーズンのうちに何回実施できるでしょうか？
  1. 2回
  2. 1回
  3. 3回
  4. 制限なし
答え2回

解説：監督ノートでは、シーズン中に2回キャンプが実施されると説明されています。キャンプでは全体練習が強化され、練習効果量の増加や全体練習メニューLvの上昇などの効果があります。

第2回サカつく検定 5日目の答え【10月11日】

5日目・第1問公式正解確認済み
「監督強化」でモチベーターLvを上げると上昇できるのは次のうちどれでしょうか？
  1. 疲労
  2. オファー成功率
  3. 連携値
  4. コンディション
答えコンディション

解説：監督ノートでは、コンディションは監督アビリティの効果によって変化すると説明されています。モチベーターは選手の状態を整える系統の監督強化で、選択肢の中では「コンディション」が該当します。

5日目・第2問公式正解確認済み
「マイタウン」でスタジアムを増築した際に、アップしないものはどれでしょうか？
  1. スタジアムレベル
  2. クラブハウスレベル
  3. 収容人数
  4. 施設スペース
答えクラブハウスレベル

解説：監督ノートでは、スタジアムを増築すると最大収容人数と施設スペースが増え、スタジアムLvも上昇すると説明されています。一方、クラブハウスはスタジアムLvが上がることで増築できるようになりますが、スタジアム増築だけでクラブハウスLvが直接上がるわけではありません。

5日目・第3問公式正解確認済み
「監督強化」でフィジカルマネジメントLvを上げると、効果を得られるのは次のうちどれでしょうか？
  1. 覚醒Ptの上昇
  2. フィジカルの上昇
  3. 疲労のたまり方の減少
  4. 年俸の上昇
答え疲労のたまり方の減少

解説：監督ノートでは、監督アビリティによって選手の疲労をたまりにくくしたり、疲労回復速度を上げたりできると説明されています。フィジカルマネジメントLvの効果として、選択肢では「疲労のたまり方の減少」が該当します。

6日目・第1問公式正解確認済み
サカつくモードで「選手人気が高い選手」が所属していると試合結果時に上昇するものはどれでしょうか？
  1. 試合のファウル数
  2. サポーター人数
  3. 相手クラブランク
  4. スタジアム満足度
答えサポーター人数

解説：監督ノートでは、選手人気が高い選手が所属していると一般観客数やHOMEサポーター観客数が増えるほか、試合結果でサポーター人数が増えやすくなると説明されています。そのため正解は「サポーター人数」です。

6日目・第2問公式正解確認済み
サカつくモードで選手のコンディションが「怪我」の際の影響は次のうちどれでしょうか？
  1. 投資できなくなる
  2. 個性が獲得できない
  3. 特別練習が行えない
  4. 移籍できなくなる
答え特別練習が行えない

解説：監督ノートでは、怪我状態の選手は練習や試合に出られず、パラメータ経験値を獲得できず、特別練習も行えないと説明されています。選択肢の中では「特別練習が行えない」が該当します。

6日目・第3問公式正解確認済み
選手同士の「選手相性」が悪い場合、該当選手に影響を及ぼすものはどれでしょうか？
  1. 疲労
  2. スタミナ
  3. コンディション
  4. パス
答えコンディション

解説：監督ノートでは、選手相性が良い選手がいるとコンディションが上昇し、相性が悪い選手がいるとコンディションが低下すると説明されています。相性効果による変化量は、相性が良い・悪い選手の人数に応じます。

第2回サカつく検定 7日目の答え【10月13日】

7日目・第1問公式正解確認済み
ユース選手の「育成方針」に【含まれない】項目はどれでしょうか？
  1. パス重視
  2. バランス
  3. シュート重視
  4. オフェンス重視
答えオフェンス重視

解説：監督ノートでは、ユースの育成方針は対応する全体練習メニューで得られるパラメータ経験値に影響し、「バランス」は全練習メニューを同程度に伸ばす方針と説明されています。当サイトで扱う全体練習の系統にはシュート・パスなどがありますが、「オフェンス重視」という育成方針は含まれないため、正解は「オフェンス重視」です。

7日目・第2問公式正解確認済み
ユースから昇格した選手を、放出または代替選手として指定するには何か月経過する必要があるでしょうか？
  1. 24か月
  2. 6か月
  3. 1か月
  4. 12か月
答え12か月

解説：監督ノートでは、ユースからトップ昇格して獲得した選手は、入団から12か月経過するまで放出できず、代替選手としての移籍オファーも発生しないと説明されています。そのため正解は「12か月」です。

7日目・第3問公式正解確認済み
ユース選手は何シーズン在籍することができるでしょうか？
  1. 3シーズン
  2. 2シーズン
  3. 4シーズン
  4. 1シーズン
答え3シーズン

解説：監督ノートでは、ユース選手は3シーズンの間在籍でき、トップ昇格させずに3シーズンが経過した選手はユースリストから抹消されると説明されています。そのため正解は「3シーズン」です。
